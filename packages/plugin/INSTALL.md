# Installing the codesignflo plugin (Figma desktop)

1. Unzip this folder somewhere permanent (e.g. `Documents/CoDesignFlo`). Don't move it afterwards.
2. In the **Figma desktop app**, open any design file → menu **Plugins → Development → Import plugin from manifest…** → choose `manifest.json` in this folder.
3. Run it from **Plugins → Development → CoDesignFlo**.

**Updates:** download it again (https://codesignflo.com/plugin.zip, or where you got it) and replace the files in the same folder with the new version. No re-import needed.
The plugin works on the free Figma plan. It only runs in the desktop app, not in the browser.
