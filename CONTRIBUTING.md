# Contributing

Thanks for helping. This repository is a public copy of CoDesignFlo, updated with every release.

- **Bugs and ideas:** open an issue. For security problems, see SECURITY.md instead.
- **Pull requests:** welcome. Keep them focused, with a test for the change (`pnpm test`, and `pnpm -C service test`
  for the service, which needs a local Supabase: `pnpm -C service db:start`). We apply accepted changes in our main
  repository, and they appear here with the next release, with you credited as the author.
- By contributing you agree that your contribution is licensed under the license of the folder you change
  (see LICENSE.md).
